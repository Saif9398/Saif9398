## Featured Project — Clipping Tool

[**Clipping Tool**](https://github.com/Saif9398/Clipping-Tool) is an AI-powered video repurposing pipeline that converts long-form videos into vertical short-form clips.

It combines speech transcription, scene analysis, candidate scoring, human clip selection, speaker-aware reframing, word-synced captions, and FFmpeg rendering. A local web UI and CLI run the same processing engine.

The project demonstrates video processing, computer vision, configurable AI scoring, and synthetic rendering tests. It currently runs as a local application; a hosted multi-user SaaS is a future direction.

**Built with:** Python · FastAPI · faster-whisper · OpenCV · MediaPipe · FFmpeg
